Measured on , one machine, simulated radio. Replay uses the real per-frame results of those runs. The model uses the same loss rule per radio frame (old stack: any lost uplink loses the frame; moq-lora: one repair frame per 8 rebuilds one loss in a block) and the frame counts of the demo's video; it is a simulation, not another benchmark. "Playable" is the demo's GOP rule: a lost frame spoils the rest of its group. A single measured run is one random draw, so it can sit away from the average. LoRaWAN is the better fit for small sensor readings and for range; see the README next to this page. The MoQ model, from moq.dev. Source: demo/oldstack. Numbers come from results/results.json.
